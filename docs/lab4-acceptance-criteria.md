# Lab 4 Acceptance Criteria



The following acceptance criteria cover every high-priority user story.



## US-01: Create a Property Listing



Given that a property professional is creating a listing,

When all required property information is entered and submitted,

Then the platform saves the listing and displays the correct title, address, price, status, bedrooms, bathrooms, square footage, image, and details link.



## US-02: Update Property Information



Given that an existing property listing is available,

When the property professional changes its price or listing status,

Then the platform saves and displays the updated information without showing the previous information.



## US-04: Find Relevant Properties



Given that multiple property listings are available,

When a buyer or renter selects search filters,

Then the platform displays only the properties that match the selected criteria.



## US-05: Manage Sponsor Information



Given that a local sponsor is entering business information,

When the sponsor submits a valid business name, description, service information, image, and website link,

Then the platform saves and displays the sponsor information accurately.



## US-07: Access the Platform



Given that a visitor uses a keyboard or assistive technology,

When the visitor navigates through the platform,

Then every interactive element is reachable, clearly labeled, visible when focused, and understandable without relying only on images or color.
