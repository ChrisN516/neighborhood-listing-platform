# Lab 4 User Stories



These user stories are based on the simulated interview evidence and represent current working hypotheses.



## US-01: Create a Property Listing



Priority: High



As a property professional, I want to create a structured property listing so that potential buyers and renters can find accurate property information.



## US-02: Update Property Information



Priority: High



As a property professional, I want to update prices and listing statuses so that visitors do not see outdated information.



## US-03: Approve Property Content



Priority: Medium



As a listing agent, I want to review and approve a listing before publication so that incorrect information is not made public.



## US-04: Find Relevant Properties



Priority: High



As a potential buyer or renter, I want to search and filter property listings so that I can find properties that meet my needs.



## US-05: Manage Sponsor Information



Priority: High



As a local sponsor, I want to submit and update my business information so that nearby residents can find accurate information about my services.



## US-06: Approve Sponsor Content



Priority: Medium



As a business owner or authorized manager, I want to approve sponsor content before publication so that my business is represented accurately.



## US-07: Access the Platform



Priority: High



As a visitor with a disability, I want keyboard navigation, readable labels, image descriptions, and sufficient color contrast so that I can use the platform independently.



## US-08: Measure Platform Success



Priority: Medium



As a platform team member, I want to track listing accuracy, visits, inquiries, and referrals so that I can determine whether the platform is successful.
